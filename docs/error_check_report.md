# Отчёт о проверке ошибок

Дата: 2026-02-05

## Проверка целостности и работоспособности

1. `python -m compileall -q benchmarks zerolink pynexus_rex tests`
   - **Результат:** успешно.
   - **Смысл:** синтаксических ошибок Python в бенчмарках, пакетах и тестах не обнаружено.

2. `pytest -q`
   - **Результат:** падение на этапе collection.
   - **Ошибка:** `ModuleNotFoundError: No module named 'torch'` при импорте `zerolink.core.gpu.vmm_pool`.
   - **Примечание:** установка зависимостей через pip заблокирована в этом окружении (proxy возвращает `403 Forbidden`), поэтому отсутствующую runtime-зависимость установить невозможно.

## Бенчмарк (реальный прогон в текущем окружении)

Команда:

- `python benchmarks/performance_comparison.py --size-mb 32 --repeats 3`

Результаты:

- **Pipe + pickle(bytes):** среднее `0.753876 s`, пропускная способность `0.041 GiB/s`
- **SharedMemory zero-copy read:** среднее `0.000062 s`, пропускная способность `502.183 GiB/s`
- **PyTorch CUDA roundtrip:** пропущен (`torch`/CUDA недоступны)

## Вывод

- Кодовая база синтаксически корректна.
- Полная runtime-проверка через pytest в текущем окружении блокируется отсутствием `torch` и ограничениями на установку зависимостей.
- IPC microbenchmark успешно выполнен и дал измеримые значения для доступных путей передачи данных.
